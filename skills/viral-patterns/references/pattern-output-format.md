# Pattern Output Format

Return patterns in a form that can be reused by `write-article`.

## Preferred Sections

1. Viral title formulas
2. Common structure patterns
3. Emotional triggers
4. Notes on what not to copy mechanically

## Good Pattern Summary

- Formula: `[Number] + [Specific outcome]`
- Emotional trigger: urgency, curiosity, identity, fear of missing out
- Structure: pain point -> evidence -> turning point -> usable action

Always separate reusable structure from the original surface wording.

When the next step is article drafting, return the pattern output in a way that can be attached to the article brief instead of living as a separate orphaned note.
