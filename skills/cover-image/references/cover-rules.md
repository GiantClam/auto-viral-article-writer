# Cover Rules

## Composition

- person on the right side of the frame
- clean text space on the left
- warm, high-contrast, professional look

## Output Path

- `output/images/wechat/{slug}-cover-final.png`

This file should ideally belong to the same slug family as:

- `output/briefs/{slug}-brief.yaml`
- `output/wechat/{slug}-article.md`

## Prompt Intent

The image should leave room for later text overlay and should not render embedded title text unless the workflow explicitly changes.

## Avoid

- watermarks
- signatures
- clutter in the text area
- weak contrast in the main subject
