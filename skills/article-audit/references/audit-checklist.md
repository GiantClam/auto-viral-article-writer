# Audit Checklist

For one article slug, check the following.

## Required For Brief-First Workflow

- `output/briefs/{slug}-brief.yaml`
- `output/wechat/{slug}-article.md`

## Required For Publish-Ready Family

- brief file
- article draft
- cover image

## Optional But Expected In Illustrated Workflows

- one or more inline images using the same slug family

## Naming Consistency

- all family files use the same slug root
- no conflicting near-duplicate slugs exist for the same article
- if a brief file exists, later artifacts should normally inherit its slug
