# Ingestion Shape

When writing to ViralKB, keep entries structured and reusable.

## Useful Fields

- keyword
- title
- title pattern
- structure
- emotional triggers
- engagement score
- source
- url
- channel

## Quality Notes

- do not ingest low-signal duplicates
- prefer reusable structure over one-off hype
- preserve enough source metadata to support later lookup and filtering
