# Research Sufficiency For Ingestion

Only ingest examples that will still be useful later when someone queries ViralKB.

## Good Ingestion Candidates

- traceable source
- clear title structure
- meaningful emotional or structural signal
- strong enough detail to reuse as a pattern

## Weak Ingestion Candidates

- vague trend chatter
- duplicates with no new information
- spikes with no identifiable angle or structure

If an item is interesting but weak, return it in the discovery list without writing it into ViralKB.
