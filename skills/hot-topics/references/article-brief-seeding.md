# Article Brief Seeding

When a topic looks strong, do not return only a ranked item. Return enough structure to help the next skill build an article brief.

## Useful Seed Fields

- topic
- possible angle
- audience guess
- HKR notes
- hook candidate
- top supporting sources
- caution or risk notes

## Example Seed

- topic: Claude Code workflow standardization
- angle: the change is less the tool and more the normalized workflow behavior
- audience: AI practitioners following agent tooling
- HKR: H strong, K strong, R medium
- hook: everyone is arguing about the tool, but the real shift is operational
- risk: trend size should not be overstated without direct metrics
