# Platform Output Spec

## WeChat

- Longer form
- Clear section structure
- Multiple title candidates at top
- Illustration-ready headings using `**Section Heading**`
- Save under `output/wechat/`, preferably as `output/wechat/{slug}-article.md`

## Xiaohongshu

- Shorter and denser
- Faster hook
- More mobile-scannable paragraphs
- Save under the appropriate short-form output directory if used

Prefer explicit platform framing over vague "general article" output.
