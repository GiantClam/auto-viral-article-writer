# setup

## Purpose

First-time configuration and environment verification for the skill package.

## Use Cases

- first install
- updating user topic preferences
- checking whether the package is ready to use

## Trigger Examples

- `setup`
- `配置`
- `设置`
- `configure this package`

## Inputs

- preferred topics
- preferred platforms
- optional re-check request

## Outputs

- `config/user_preferences.json`
- setup summary
- next-step guidance

## Boundary

Use `setup` to prepare the environment, not to write articles or generate images.
