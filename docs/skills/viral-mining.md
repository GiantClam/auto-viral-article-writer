# viral-mining

## Purpose

Discover high-signal content across multiple sources and write reusable entries into ViralKB.

## Use Cases

- growing ViralKB from fresh content
- building a pattern corpus before writing
- multi-platform topic mining

## Trigger Examples

- `挖掘爆款`
- `发现爆款`
- `viral mining`

## Inputs

- keyword
- optional source restrictions
- optional result limit

## Outputs

- ranked discovery list
- ViralKB ingestion summary

## Boundary

Use `viral-mining` to create future pattern assets. Use `viral-patterns` to query those assets later.
