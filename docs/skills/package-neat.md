# package-neat

## Purpose

Sync package-facing docs, indexes, manifests, and release-facing metadata after changes to the skill package.

## Use Cases

- release cleanup
- repository consistency checks
- updating docs after adding or restructuring skills

## Trigger Examples

- `整理一下`
- `同步文档`
- `release audit`
- `skill audit`

## Outputs

- synced package docs
- updated manifest or index files
- final consistency summary

## Boundary

This is a maintenance and release-readiness skill, not a content-production skill.
