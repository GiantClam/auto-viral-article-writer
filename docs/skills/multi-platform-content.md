# multi-platform-content

## Purpose

Run the end-to-end multi-platform content workflow from mother draft to repurposing, scoring, prediction, and retrospective.

## Use Cases

- one topic becoming a WeChat mother draft plus X, Xiaohongshu, TikTok, Reddit, dev.to, or Facebook versions
- a repeatable content operations workflow with a ledger and platform rubrics

## Trigger Examples

- `做一套多平台内容包`
- `run the multi-platform content workflow`
- `turn this topic into a mother draft plus distribution posts`

## Inputs

- topic
- target platforms
- optional launch goal

## Outputs

- WeChat mother draft
- platform-native variants
- score files
- prediction files
- retro files
- rubric update candidates

## Workflow Summary

1. `write-article`
2. `cover-image`
3. `repurpose-content`
4. `article-score-retro` score
5. `article-score-retro` predict
6. publish
7. `article-score-retro` retro
8. `platform-rubric-manager` update when needed
