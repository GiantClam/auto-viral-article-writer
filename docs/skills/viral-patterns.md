# viral-patterns

## Purpose

Retrieve reusable title formulas, emotional triggers, and structure patterns from ViralKB.

## Use Cases

- title ideation
- structure benchmarking
- pattern-assisted outlining

## Trigger Examples

- `爆款模式`
- `找标题公式`
- `参考爆款`
- `viral patterns`

## Inputs

- topic keyword
- optional output emphasis such as title-only or structure-only

## Outputs

- ranked pattern summary
- title formulas
- suggested structure shape
- pattern fields that can attach to an article brief

## Boundary

Use `viral-patterns` for local pattern reuse, not live topic discovery.

When the next step is drafting, return findings in a shape that can attach to `templates/article-brief.yaml`.
